# WellAgent — ИИ-агент для анализа нефтяных скважин

## О проекте

WellAgent — учебный проект по разработке ИИ-агента, который помогает инженеру анализировать работу нефтяных скважин с помощью инструментов MCP.

## Цель проекта

Разработать ИИ-агента, способного получать параметры скважин, запускать инженерные расчёты и представлять результаты на естественном языке.

## Основные возможности

- Получение информации о скважинах.
- Расчёт рабочей точки скважины методом узлового анализа.
- Анализ истории добычи.
- Прогнозирование дебита скважины.
- Взаимодействие с MCP-сервером WellLab.

## Технологии

- Python
- OpenAI API
- Model Context Protocol (MCP)
- GitHub
